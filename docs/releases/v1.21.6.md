# Save Garage 简体中文版 1.21.6

本版接续本仓库的 `v1.25.0-zh.2`，同步原作者 `v1.26.0` 及其之后的游戏编号更新，合并至上游提交 `1906f33`。本仓库的发行编号为 `1.21.6`。[上游改动对比](https://github.com/NotHGM/save-garage/compare/v1.25.0...1906f3349183b25555adc45b0ca198dcbea4a2f9)

- **银行余额**。编辑器现在读取每个银行钱箱内的全部资金记录。调高余额时会先填充已有资金堆，再按需在 85,000 面额的钱箱内新增资金堆；调低余额时保留空行供下次复用。程序会预留 300 个库存条目。上游给出的后期档示例约可达 2.3 亿游戏币，实际可设上限取决于当前槽位的钱箱与剩余空间。上游将新增资金堆标为尚待本项目 PS5 实机复核。[银行实现](https://github.com/NotHGM/save-garage/commit/a80c1d7)
- **车辆图鉴**。通过游戏车辆数据确认 69 个图鉴标识，其中 64 个此前来自推断。新增可选的五款车型为 Crusher、Double-T、Forklift、Telehandler 和 Vigero ZX。[图鉴更新](https://github.com/NotHGM/save-garage/commit/97fa04d)
- **存档下载**。新增识别游戏编号 `PPSA29660`，支持列表现为 `PPSA01547`、`PPSA38500`、`PPSA29660`。[游戏编号更新](https://github.com/NotHGM/save-garage/commit/1906f33)
- **界面说明**。金额编辑页增加资金堆提示，补全现金字段名和修改前金额提示的多语言翻译。原作者还在 README 中加入了游戏哈希数据库入口，本地上一版已包含该链接。[哈希数据库](https://github.com/NotHGM/gta6-hash-database)

简体中文版继续提供已知存档项目、按角色调整成长值、所选统计一键拉满、靶场逐课成绩和启动器旁的 `saves` 下载目录。
