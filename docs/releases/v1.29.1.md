# Save Garage 简体中文版 1.29.1

同步原作者 1.27.0 至 1.29.1 的八个提交。[上游改动](https://github.com/NotHGM/save-garage/compare/1906f3349183b25555adc45b0ca198dcbea4a2f9...4ca09334844f91ed095d7a5486766fa3a8a22ab2)

- 世界页可揭开已识别区域的地图迷雾，还可调整两位主角的特殊能力槽、技能、犯罪侧写、防弹衣和关系分数。各项的验证状态见编辑页面。
- 武器页支持给角色添加尚未持有的武器，完成度页可选择解锁游戏秘籍。
- 下载详情分别记录主机响应与密钥服务耗时。服务返回限流、密钥受限或请求有误时，界面会给出对应原因。
- 本分支的靶场逐课成绩、逐项成长编辑、已知字段页和启动器旁的存档目录继续可用。
- 源码版默认使用本分支此前发行包的分发密钥。本机可通过配置文件的 `workerKey` 或环境变量 `GARLIC_WORKER_KEY` 覆盖，配置文件优先。打包时仍支持仓库的 `SAVEGARAGE_RELEASE_WORKER_KEY`。
