# MoonSlot 1.30.1

MoonSlot 是 HelloMoon-1 维护的非官方修改版。Based on Save Garage by NotHGM (https://github.com/NotHGM/save-garage)。

- 同步上游 1.30.0 和 1.30.1。配对、下载、加密、回传和续解密使用每位玩家自己的 GarlicSaves 账号，首次通过官网设备码授权。发行包不再附带或注入共享 worker key。
- 银行金额默认按当前剧情存档的可消费容量限制。旧存档超出容量时可调整到可消费范围，也可以主动开启实验性超额金额。
- 主界面首次打开会提示给 NotHGM 的原项目点 Star，可直接关闭。界面和三个平台的发行包使用 MoonSlot 的名称与图标。
- 自动更新从本仓库获取，安装前验证 MoonSlot 独立签名。保留本分支的批量解密、队列详情、断线重连、续解密与存档时间显示。
