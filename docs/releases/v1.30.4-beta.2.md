# GTA6 剧情存档编辑器 1.30.4 beta 2

供 PS5 Pro 回传兼容性实测使用。包含按硬件类型选择主机信息布局、自动选择当前网卡的 IPv6 地址，以及 IPv6 数据连接使用已有密钥服务的调整。主机列表等待时限为五分钟。

Windows 解压到新的文件夹，运行 `Start MoonSlot.bat`，页面底部应显示 `1.30.4 (beta 2)`。回传前先保留可恢复的原始存档备份。请分别记录回传是否完成，以及游戏是否成功读取传回的存档。

已通过 Python 语法检查和现有 14 项测试。新增适配的 PS5 Pro 实机效果待验证。问题反馈请附错误代码和对应阶段，分享日志前隐去账号、设备标识及网络地址。
